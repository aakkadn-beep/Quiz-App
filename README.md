# Quiz-App
Descripción:
Será una aplicación donde el usuario podrá responder una serie de preguntas de opción múltiple para poner a prueba sus conocimientos

# User stories:

* Como usuario, quiero iniciar el cuestionario mediante un botón para comenzar a responder las preguntas.

* Como usuario, quiero visualizar una pregunta con cuatro posibles respuestas para seleccionar la que considero correcta.

* Como usuario, quiero seleccionar una respuesta para poder continuar con la siguiente pregunta.

* Como usuario, quiero que las preguntas aparezcan una después de otra hasta finalizar el cuestionario.

* Como usuario, quiero conocer cuántas respuestas contesté correctamente para saber mi desempeño.

* Como usuario, quiero conocer cuánto tiempo tardé en terminar el cuestionario para evaluar mi desempeño.

* Como usuario, quiero recibir un mensaje indicando si aprobé o reprobé para conocer el resultado final.

# Metodología:
Enfoque Ágil (Kanban) — Se eligió por ser un proyecto con entregas incrementales, alcance ajustable y adaptable al trabajo distribuido del equipo en pocas sesiones
